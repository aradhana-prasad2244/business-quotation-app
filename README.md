# Business Quotation App

A web application for creating business quotations and generating PDF documents.

## Features

* Enter quotation reference number and date
* Add customer details and subject
* Add multiple products or services
* Enter content, charges, and price for each item
* Automatically calculate the total amount
* Save quotation data using browser local storage
* Generate and download the quotation as a PDF
* Simple interface for creating business quotations

## Technologies Used

* HTML5
* CSS3
* JavaScript
* Vite
* jsPDF
* jsPDF-AutoTable
* Local Storage

## How to Run

### 1. Clone the repository

```bash
git clone https://github.com/aradhana-prasad2244/business-quotation-app.git
```

### 2. Navigate to the project folder

```bash
cd business-quotation-app
```

### 3. Install dependencies

```bash
npm install
```

### 4. Start the development server

```bash
npm run dev
```

Open the local URL provided by Vite in your browser.

## How to Use

1. Enter the quotation reference number and date.
2. Add the customer details.
3. Enter the quotation subject.
4. Add products or services using the **+** button.
5. Enter the item content, charges, and price.
6. Add additional items as required.
7. The total amount is calculated automatically.
8. Click **Download PDF** to generate the quotation.

## Data Storage

Quotation data is stored in the browser's **Local Storage**, allowing quotation information to be saved locally on the user's device.

## Project Purpose

This project was created to simplify the process of creating business quotations by providing an easy way to enter quotation details, calculate the total amount, save the data locally, and generate a downloadable quotation document.
